The type level

Every ontological rule in this language rests on something said about a type: what identity its instances carry, whether they can stop being instances, what they may be, and at which classification level they sit. Those four properties, the six principles that combine them, and the {{SIZE}}×{{SIZE}} table the principles decide — computed here, not transcribed.

{{COUNTS}}

What a stereotype fixes

Four properties, and every one of them is a claim about the instances. Sortality says whether they carry a principle of identity and where it comes from; rigidity, whether one can stop being an instance and go on existing; the natures, what sort of thing they may be; the order, whether they are themselves types. Nothing else about a stereotype is load-bearing.

The natures, in tiers

A lattice, not a flat set of labels: comparing natures by string equality gets subsumption wrong in both directions. objects is the one name standing for several, and the tiers below are what the rules actually ask for — anti-rigidity asks whether instances can change, which is not the same question as whether they endure.

The six principles

Each refuses a share of the {{PAIRS}} ordered pairs, and the counts are computed by asking the implementation, pair by pair, why it says no. A refusal names its principle rather than restating a table, which is the point of having them: the taxonomy is not a list to maintain.

Types of types

The order of a type is where the type level folds back on itself: an instance of an order-n type is an order-(n−1) type. tonto says it with the types nature and an instanceOf clause rather than with an integer, and the multi-level rules are the axiomatized theory of Carvalho and Almeida read as checks.

powertype-does-not-classify-typesA Cardelli power type holds every specialization of its base, and specializations are types — so "isPowerType" only says something on a class restricted to types. It is a modifier rather than a stereotype because what the class is stays open: a "type", a "category of types" and a "class of types" may each carry it.
powertype-without-baseA power type is defined by the type it is the power type of (MLT D3).

powertype-as-categorizerA power type supplies no classification criterion, so it categorizes nothing.

Where the type level reaches the individual level

These are rules about relations, parts, properties and instants — and each one asks a question about a type before it can decide. That is what makes them ontological rather than structural: the same diagram means different things under different stereotypes.
